# 6가지 랜딩 유형 상세 스펙

유명 브랜드 랜딩 30개(글로벌 테크 10 · 한국 10 · 라이프스타일 10) 실측 분석에서 도출.
각 유형은 "팔레트 공식 → 타이포 → 섹션 골격 → 모션 → 카피 톤 → 흔한 실수" 순서.
토큰 예시는 그대로 써도 되고, 브랜드 고유색이 있으면 같은 역할(그라운드/액센트)로 치환한다.

---

## 유형 1 · 임팩트 캠페인형
ref. Nike · Gentle Monster · Red Bull · 무신사 · Spotify

**무드**: 캠페인 포스터. 화면이 소리를 지른다. 색은 캠페인(이미지·액센트)이 전부 가져가고 크롬은 무채색.

**팔레트 공식**: 검정 그라운드 + 형광/비비드 액센트 1색 + 흰 텍스트.
```css
--bg:#0A0A0A; --surface:#141414; --card-bg:#141414;
--fx-accent:#D6FF3F; /* volt. 대안: #FF3B30, #00FF85 */ --fx-accent-ink:#0A0A0A;
--nav-bg:rgba(10,10,10,.88); --radius:0px; /* 각진 프레임이 스포츠 캠페인의 언어 */
```

**타이포**: 디스플레이 900 웨이트, 대문자, `letter-spacing:-0.03em`, `line-height:.95~1.05`,
`clamp(56px,12vw,160px)`까지 키운다. 아웃라인 텍스트(`-webkit-text-stroke`)로 한 단어 강조.

**섹션 골격**: ① 킥커+초대형 슬로건 히어로(블록형 CTA 1개) → ② 얇은 라인 스탯 스트립(티커)
→ ③ 빠른 마퀴(24~30s) → ④ 풀블리드 캠페인 블록 2~3개(21:9 이미지 + 하단 걸침 대문자 타이틀
+ "View Campaign" 언더라인 링크) → ⑤ 각진 상품/작업 그리드(gap 2px, 보더가 그리드선)
→ ⑥ 초대형 마감 CTA.

**모션**: 크고 빠르게 — 마퀴 최고속, 캠페인 이미지 `grayscale(.25)`→호버 시 컬러+`scale(1.05)`,
CTA는 `translate(-3px,-3px)` + 하드 섀도(블러 0).

**카피 톤**: 명령형, 짧게, 영문 헤드라인 허용. "Show Your Spark", "Just Prove It".

**흔한 실수**: 라운딩을 주는 것(999px pill은 이 유형에서 금지, CTA는 각진 블록),
회색 본문을 길게 쓰는 것 — 본문은 2줄 이내.

## 유형 2 · 프로덕트 몰입형
ref. Apple · Tesla · 현대카드 · LG전자 · 유니클로

**무드**: 쇼룸. 제품 사진이 곧 레이아웃이고 카피는 캡션이다. 크롬은 존재감을 지운다.

**팔레트 공식**: 흰 그라운드 + `#F5F5F7` 교차 슬라이드 + 잉크 텍스트, 액센트는 링크/CTA에만.
```css
--bg:#FFFFFF; --surface:#F5F5F7; --text-primary:#1D1D1F;
--fx-accent:#0071E3; --fx-accent-ink:#FFFFFF;
--nav-bg:rgba(255,255,255,.82); --radius:18px;
```

**타이포**: 중앙 정렬, `clamp(34px,6vw,64px)` 700 웨이트, `-0.025em`. 카피는 헤드라인 한 줄
+ 태그라인 한 줄 + 링크 페어("구매하기" 채움 pill / "더 알아보기 →" 텍스트)가 전부.

**섹션 골격**: ① 선언 한 줄 히어로 + 대형 비주얼 → ② 제품 슬라이드 2~3개(배경 흰/회 교차,
각각 킥커/헤드라인/태그/링크페어/이미지) → ③ 반반 듀오 타일(하나는 다크 반전) → ④ 얇은
스펙·수치 밴드(티커, 조용하게) → ⑤ 다크 마감 CTA 섹션.

**모션**: 이미지가 아래에서 떠오르는 리빌(`translateY(60px)`→0), 그 외엔 거의 없음.
마퀴·스파크 필드는 쓰지 않는다.

**카피 톤**: 명사형 선언 + 마침표. "경험을, 작품으로." 수식어 최소.

**흔한 실수**: 섹션마다 CTA 넣기(링크 페어 하나면 충분), 이미지에 필터·보더 과다,
좌측 정렬(이 유형의 히어로·슬라이드는 중앙 정렬이 문법).

## 유형 3 · 전환형 SaaS
ref. Stripe · 토스 · Notion · Figma · Linear · Vercel

**무드**: 퍼널. 스크롤 전체가 "신뢰 쌓기 → 이해시키기 → 증명 → 전환"의 설계도다.

**팔레트 공식**: 흰 그라운드 + 시그니처 블러플/블루 + 다크 네이비 텍스트, 히어로에 그라디언트.
```css
--bg:#FFFFFF; --surface:#F6F8FB; --text-primary:#0A2540;
--fx-accent:#635BFF; /* 대안: #3182F6(토스풍) */ --fx-accent-ink:#FFFFFF;
--nav-bg:rgba(255,255,255,.85); --radius:14px;
```
히어로 배경: `skewY(-7deg)` 사선 그라디언트 레이어(opacity ~.14) + `background-position` 애니메이션.

**타이포**: `clamp(34px,5.6vw,62px)` 800, 헤드라인 일부에 그라디언트 텍스트
(`background-clip:text`). 본문은 회색 550px measure.

**히어로 구성**: 좌측 텍스트 / 우측 비주얼의 2단이 이 유형의 실제 골격이다(Stripe·Linear·토스 모두).
사진이 없으면 CSS만으로 제품 UI 목업을 그린다 — 창 프레임 + 신호등 점 3개 + 텍스트 줄 몇 개 +
액센트 뱃지 하나면 충분하고, 여기에 제품의 핵심 가치(예: "작성 시간 92%↓")를 얹으면 히어로가
설명 없이 이해된다. 우측을 비워 좌측 정렬 한 덩어리로만 두면 데스크톱에서 미완성으로 보인다.

**섹션 골격**: ① 배지(수상/1위) + 헤드라인 + **듀얼 CTA**(채움 "시작하기" + 고스트 "살펴보기") + 우측 목업
→ ② 신뢰 로고 스트립(마퀴 40s, 저채도) → ③ 벤토 피처 그리드(wide 셀 섞기, 아이콘+제목+본문)
→ ④ 다크 그라디언트 수치 밴드(티커 4개) → ⑤ 후기 카드 3개(실제 후기만) → ⑥ 마감 CTA(채움 버튼 재등장).

**모션**: 호버 리프트 + 액센트 링/섀도, 그라디언트 슬로우 시프트, 리빌. CTA 호버는
`translateY(-2px)` + 컬러 섀도.

**카피 톤**: 혜택 중심 동사형. "커리어의 다음을 만드는", CTA는 행동+화살표("무료 상담 시작 →").

**흔한 실수**: CTA 문구가 섹션마다 다른 것(같은 행동, 같은 문구로 반복해야 전환됨),
벤토 셀마다 이미지 넣기(1~2개만), 후기 창작, 최종 CTA를 `href="#"`로 두는 것
(전환형인데 신청 경로가 없으면 유형의 목적 자체가 무너진다 — 폼이나 실제 링크를 붙인다),
수치 밴드를 기능 설명보다 앞에 두는 것(무엇인지 모르는 상태의 숫자는 설득하지 못한다).

## 유형 4 · 헤리티지 내러티브형
ref. 신도리코 · 네이버 · 카카오 · 우아한형제들 · Lush

**무드**: 사사(社史)의 첫 장. 팔지 않고 선언한다. 제품·서비스는 스토리가 끝난 뒤에야 나온다.

**팔레트 공식**: 흰 그라운드 + 잉크 텍스트 + 절제된 시그니처 1색(아주 아껴서).
```css
--bg:#FFFFFF; --surface:#F7F8FA; --text-primary:#17191D;
--fx-accent:#C8351F; /* 챕터 번호·라벨·화살표에만 */ --fx-accent-ink:#FFFFFF;
--nav-bg:rgba(255,255,255,.9); --radius:6px;
```

**타이포**: 국문 대형 헤드라인 `clamp(30px,4.6vw,52px)` 700 + **EN 슬로건 병기**
(레터스페이싱 .32em 대문자 소형) — 이 병기가 유형의 시그니처다(신도리코 실측).

**섹션 골격**: ① CTA 없는 브랜드 선언 히어로(EN 슬로건 → 국문 헤드라인 → since 라인)
→ ② 잔잔한 마퀴(55s, 협업사) → ③ 스토리 챕터 2~3개(좌 번호라벨 / 우 본문 2단 그리드,
첫 챕터에만 수치 티커) → ④ 사례 카드 3단(회색 표면 위) → ⑤ 뉴스 리스트(날짜+제목+화살표)
→ ⑥ 다크 반전 슬로건 리프라이즈 + 여기서 처음이자 마지막 CTA.

**모션**: 조용한 페이드 리빌뿐. 호버도 배경 톤 변화 정도.

**카피 톤**: "~위에, ~을 만듭니다" 구조의 신뢰 선언문. 1인칭 회사/브랜드 시점.

**흔한 실수**: 히어로에 CTA 넣기(이 유형은 참는 게 문법), 스토리 챕터를 카드 그리드로
바꾸는 것(줄글 2단이어야 사사 느낌이 남), 액센트 남용.

## 유형 5 · 콰이어트 에디토리얼형
ref. Aesop · 무인양품 · Anthropic · Patagonia · Freitag

**무드**: 문예지. 카피가 이미지보다 먼저고, 여백과 타이포가 신뢰를 만든다.

**팔레트 공식**: 아이보리 그라운드 + 잉크 + 테라코타 1색, 이미지에 저채도 필터.
```css
--bg:#F0EEE6; --surface:#E7E4D8; --card-bg:#F7F5EE; --text-primary:#1F1D1A;
--fx-accent:#B0552F; --fx-accent-ink:#F0EEE6;
--nav-bg:rgba(240,238,230,.9); --radius:2px;
--font-display:'Noto Serif KR',serif; /* Google Fonts 링크 필요 */
```
이미지 공통 필터: `filter:sepia(.08) saturate(.92)`.

**타이포**: 세리프 디스플레이(600) + 산세리프 본문. 히어로 `line-height:1.55`로 느슨하게,
이탤릭 세리프로 한 단어 강조. 본문 measure 640px, `line-height:2`.

**섹션 골격**: ① 카피 온리 히어로(오버라인 → 세리프 2행 헤드라인 → 각주 라인)
→ ② 에세이 단락(세리프 리드 + 본문 2~3단락 + 이탤릭 서명) → ③ 오브제 진열 2~3개
(이미지/텍스트 좌우 교차, "기록 읽기" 언더라인 링크) → ④ 조용한 수치 라인(세리프 30px, 작게)
→ ⑤ 서가(3:4 세로 이미지 3개) → ⑥ 편지형 마감(세리프 헤드라인 + 각진 고스트 버튼).

**모션**: 리빌 duration을 1.2s로 늘린다(`.reveal{transition-duration:1.2s}`). 호버는
`translateY(-6px)` 정도. 마퀴·스파크·그라디언트 금지.

**카피 톤**: 완결된 문장, 은유 허용. "경험은 나열될 때 흩어지고, 편집될 때 이야기가 됩니다."
CTA도 문학적으로("편지 쓰기").

**흔한 실수**: 세리프를 본문까지 쓰는 것(디스플레이만), 비비드 색 유입, 섹션 과밀 —
이 유형은 섹션을 줄일수록 좋아진다.

## 유형 6 · 커머스 큐레이션형
ref. Airbnb · IKEA · 29CM · 이니스프리

**무드**: 셀렉트샵. 마케팅 히어로 대신 검색·탐색 UI가 첫 화면이고, 본체는 카드 그리드다.

**팔레트 공식**: 흰 그라운드 + 비비드 코랄/브랜드색 1색 + 밝은 회색 표면.
```css
--bg:#FFFFFF; --surface:#F7F7F7; --text-primary:#222222;
--fx-accent:#FF385C; --fx-accent-ink:#FFFFFF;
--nav-bg:rgba(255,255,255,.92); --radius:16px;
```

**타이포**: 헤드라인은 작게(`clamp(24px,3.6vw,38px)` 800), 카드 메타(제목 15px + 평점 +
설명 + 가격 라인)가 진짜 타이포 시스템. 평점 별은 액센트색.

**섹션 골격**: ① 한 줄 질문형 헤드라인 + **필 검색바**(세그먼트 2~3개 + 원형 액센트 버튼)
→ ② 이모지 카테고리 아이콘 행(언더라인 액티브) → ③ 필터 칩 + 카드 그리드(1:0.95 이미지,
BEST/인기 뱃지, 찜 하트 버튼, 제목·평점·설명·가격 메타) — `fxFilterAppear`로 전환
→ ④ 기획전 타일 2개(16:8 이미지 + 하단 그라디언트 캡션) → ⑤ 라운드 박스 마감 CTA.

**모션**: 카드 이미지 `scale(1.06)` 호버, 하트 `scale(1.12)`+색 전환(클릭 토글), 필터 스태거.

**카피 톤**: 쇼핑 언어. "어떤 경험을 찾으세요?", "골라 담으세요", 뱃지·평점·가격 라인 적극 사용.

**흔한 실수**: 카드 6개 미만(그리드가 비면 유형이 안 산다 — 최소 6개), 검색바를 실제
입력폼으로 만들기(앵커 링크면 충분, 백엔드 없는 정적 페이지다), 히어로에 긴 브랜드 스토리.

## 유형 선택이 애매할 때

- 이미지가 좋다 → 1·2·6 / 이미지가 없거나 약하다 → 3·4·5
- 팔 것이 하나다 → 2·3 / 여러 개다 → 6 / 파는 것보다 믿음이 먼저다 → 4·5
- 타깃이 젊고 트렌디 → 1·6 / 기업·기관 결재권자 → 3·4
- 두 유형 사이면 골격은 한쪽을 따르고 무드(색·서체)만 다른 쪽에서 빌린다 — 골격 혼합은 금지
